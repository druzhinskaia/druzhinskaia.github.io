# Екатерина Дружинская — аналитика данных и автоматизация

[Сайт](https://druzhinskaia.github.io) · [GitHub](https://github.com/druzhinskaia) · [Telegram](https://t.me/dru_zh)

Портфолио содержит проекты на собственных данных автора. Описание не подменяет проверку реализации: каждый кейс включает исходники, правила расчётов, воспроизводимые результаты или спецификацию и ограничения.

| Проект | Подтверждённые артефакты |
|---|---|
| [Контроль выгрузок 1С](portfolio-projects/01-data-quality-excel-reporting/README.md) | формулы Excel, динамический реестр, сводка, исходные выгрузки |
| [Спецификация заявок 1С](portfolio-projects/02-bpmn-1c-requirements/README.md) | процесс, требования, SLA, RTM и сценарии; эталонная логика Python |
| [Продажи и отзывы](portfolio-projects/03-sales-feedback-python-analytics/README.md) | валидация, pandas, графики, единый рейтинг и повторный запуск |
| [SQL и дашборд](portfolio-projects/04-sql-bi-dashboard/README.md) | SQLite, агрегированные витрины, выгрузки, общие фильтры месяца/канала |

Основные исходники находятся в отдельных репозиториях проектов; копии сайта синхронизируются с ними. Русская и английская версии сайта, README и PDF содержат согласованные формулировки. Собственные данные не означают автоматически измеренный эффект внедрения; результаты и ограничения указаны отдельно.

Сборка Python и SQL: соответствующие scripts/build_* вызывают опубликованные проектные конвейеры и сохраняют исходные данные. Excel-книга обновляется по формулам в указанной вместимости; скрипт пересборки требует доступного @oai/artifact-tool. PDF: `python scripts/build_resume_pdf.py`, зависимости `reportlab`, шрифты DejaVu Sans.
