# Ekaterina Druzhinskaia — data analytics and automation

[Website](https://druzhinskaia.github.io) · [GitHub](https://github.com/druzhinskaia)

The portfolio uses the author's own data and tasks: Excel export validation and an updating error register; a 1C analytical specification with SLA and traceability; reproducible Python sales/feedback analysis; and a SQLite sales mart with a browser dashboard.

Project source repositories are canonical. Site copies, bilingual README files and PDF resumes are aligned. Source ownership does not itself establish deployment or measured effects; each project documents its actual deliverables and limitations. Python/SQL rebuilds preserve source CSV files. The 1C package is a specification and reference rule model, not a deployed extension.
