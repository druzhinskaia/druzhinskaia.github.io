# Спецификация браузерного прототипа

Источник: data.js, выгруженный scripts/build.py из sales_order_mart и строк заказов. Интерфейс RU/EN, фильтры месяц заказа и канал, шесть KPI: заказы, выручка, маржа, средний чек, задолженность, переплаты. Все блоки используют один отбор. Срезы: месяц, категория, канал, топ-15 клиентов с задолженностью. Пустой отбор показывает нули и недоступные отношения; деления на ноль нет.

Изменение CSV требует повторного запуска сборки. Сегмент, регион, категория и статус как фильтры не реализованы. Power BI/PBIX — возможное дальнейшее развитие, не готовый артефакт. Модель допускает отдельные платежи; для накопительных снимков правило источника требуется изменить.
