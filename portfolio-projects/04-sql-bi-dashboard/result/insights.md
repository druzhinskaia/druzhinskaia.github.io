# Как интерпретировать результат

Данные предоставлены автором. Подтверждённые показатели находятся в пяти CSV рядом с этим файлом; их обновляет scripts/build.py. Можно сравнивать выручку, взвешенную маржу, остаток задолженности и количество заказов по срезам.

Практические следующие действия: проверить причины положительного остатка оплаты; сравнить объём и маржу категорий; изучить различия каналов с учётом ассортимента. Это направления проверки, а не доказанный эффект. Нельзя рекомендовать перераспределение рекламного бюджета только по выручке: затрат на рекламу и атрибуции нет. Остаток платежей не является исторической просрочкой без даты среза.
