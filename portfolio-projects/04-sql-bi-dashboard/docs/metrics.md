# Определения метрик

| Метрика | Правило |
|---|---|
| Продажи | неотменённые заказы из sales_order_mart |
| Выручка | сумма line_revenue, агрегированная сначала до заказа |
| Прибыль | сумма line_revenue − line_cost |
| Маржа | суммарная прибыль / выручка; при нуле недоступна |
| Средний чек | выручка / количество заказов |
| Оплачено | сумма непересекающихся платежей заказа; отсутствие = 0 |
| Задолженность | max(выручка заказа − оплачено, 0), затем сумма |
| Переплата | max(оплачено − выручка заказа, 0), затем сумма |
| Ранг канала | RANK по сумме выручки; совпадения имеют одинаковый ранг |

Средний чек канала относится к заказам, не строкам. Фильтры месяца заказа и канала применяются к одной витрине до всех агрегаций. Категории агрегируют строки только отобранных заказов. Время среза платежей неизвестно: исторический остаток и просрочка не рассчитываются.
