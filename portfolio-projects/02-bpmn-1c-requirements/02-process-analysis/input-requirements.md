# Вводные и требования участников процесса

## Менеджеры продаж

**Проблемы**

- заявки поступают из разных каналов;
- часть данных приходится уточнять после начала обработки;
- статусы ведутся вручную и различаются у разных менеджеров;
- сложно определить текущего ответственного за заявку.

**Требование к решению**

Нужна единая форма заявки с обязательными полями, подсказками и автоматическим назначением срока.

## Руководитель отдела продаж

**Проблемы**

- нет ежедневной картины по просроченным заявкам;
- отчет собирается вручную;
- проблемы становятся заметны слишком поздно;
- нет единой логики приоритетов.

**Требование к решению**

Нужен отчет по статусам, SLA, ответственным и заявкам высокого приоритета.

## Смежные подразделения

**Проблемы**

- в заявках не хватает данных для оплаты или отгрузки;
- заявку приходится возвращать менеджеру;
- отсутствует прозрачный статус ожидания уточнений.

**Требование к решению**

Нужны обязательные поля, история статусов и понятный маршрут доработки заявки.
