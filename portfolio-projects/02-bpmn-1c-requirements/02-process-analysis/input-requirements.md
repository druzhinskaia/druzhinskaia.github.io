# Исходные потребности автора

- Единый реестр заявок с ответственным и обязательными полями.
- Управляемые статусы вместо свободного текста.
- Согласование высокого приоритета и специальных категорий.
- Контроль срока, история изменений и отчёт руководителя.

Это структурирование вводных, а не протокол подтверждённого интервью. Для рабочего внедрения нужно уточнить конфигурацию и версию 1С, правила распределения категорий, руководителей, производственный календарь, транспорт уведомлений и инфраструктуру нагрузочного теста.
