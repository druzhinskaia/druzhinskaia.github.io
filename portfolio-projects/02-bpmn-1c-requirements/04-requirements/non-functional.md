# Нефункциональные требования

| ID | Проверяемое условие | Сценарий |
|---|---|---|
| NFR-01 | пользователь создаёт заявку по подсказкам; ошибки указывают конкретное поле | TS-19 |
| NFR-02 | отчёт: p95 <=10с, 10 000 заявок, 20 пользователей, 30 запусков; конфигурация и ресурсы стенда согласованы и записаны | TS-20 |
| NFR-03 | справочники меняет только администратор | TS-08 |
| NFR-04 | историю не удаляет обычный пользователь; изменения администратора отдельно аудируются | TS-18 |
| NFR-05 | ключевые поля видны на первом экране 1366×768 при 100% | TS-21 |

Требования целевые, тесты в 1С ещё не выполнены. Нагрузку 10 000 записей нельзя выдавать за доказанную производительность.
