# Диаграммы

TO-BE представлен в BPMN 2.0 XML с графической разметкой DI: [to-be.bpmn](to-be.bpmn). Это описательная модель (`isExecutable=false`), а не внедрённый процесс 1С.

Четыре дорожки: инициатор, менеджер, руководитель и исполнитель. Круги обозначают события, скруглённые прямоугольники — действия, ромбы с X — исключающие шлюзы. Сплошные стрелки показывают последовательность внутри одного пула, в том числе между дорожками. Ветви согласования, отказа, уточнения и доработки результата сохранены. Соединения ортогональные; подписи ветвей обозначают решения, а не декоративные комментарии.

Один граф используется для BPMN/DI, SVG, PNG и draw.io на русском и английском. [Интерактивный просмотр](viewer.html): масштаб, перемещение, полный экран и скачивание `.bpmn`. Просмотр работает без внешних библиотек и не имитирует выполнение процесса.

Основной маршрут не заменяет полную таблицу допустимых переходов: [status-transitions.md](../06-specification/status-transitions.md). Регламентный контроль SLA и доставка уведомлений описаны отдельно в [sla-and-notifications.md](../06-specification/sla-and-notifications.md), а не добавлены декоративными стрелками в основной процесс. AS-IS и вспомогательные схемы — отдельные прежние материалы, не экспорт этого графа.

Источник нотации: [OMG BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/), разделы 7.6, 10.6 и 10.8. Прямоугольные соединения — выбор оформления, а не обязательное требование стандарта.
