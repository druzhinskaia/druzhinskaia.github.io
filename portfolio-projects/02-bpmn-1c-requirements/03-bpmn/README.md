# Диаграммы

AS-IS, TO-BE и вспомогательные схемы иллюстрируют процесс. TO-BE.drawio и SVG/PNG содержат одинаковые ветви: необходимость согласования, решение руководителя, отказ, уточнение и возврат результата. Это схема процесса с BPMN-подобными элементами; исполняемая BPMN-модель не поставляется. Роли и допустимые переходы определены в `../06-specification/status-transitions.md`, фоновые таймеры — в `sla-and-notifications.md`.
