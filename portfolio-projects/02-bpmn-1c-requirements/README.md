## Проверка доступных артефактов

Python 3.10–3.12, стандартная библиотека:

```bash
python -m unittest discover -s tests -v
```

`reference/sla.py` — проверяемая эталонная логика рабочего календаря и статусов на Python, а не реализация 1С. Тесты проверяют выходные, явные праздничные даты, границы дня, смену приоритета и запрет переходов. Приёмочные сценарии для формы, прав, уведомлений и производительности должны быть выполнены в целевой 1С после реализации; они помечены как ожидающие выполнения.

## Происхождение и ограничения

Данные и вводные принадлежат автору. Факт интервью, внедрение и измеренный эффект нельзя подтвердить только наличием документа. Числа 200 заявок/день и 3 дня обработки, ранее включённые в описание, не используются как доказанный результат: нужен период, источник и метод измерения. SLA 1/3/5 рабочих дней и календарь 09:00–18:00 — явно заданные правила текущей спецификации, которые нужно согласовать перед разработкой.
