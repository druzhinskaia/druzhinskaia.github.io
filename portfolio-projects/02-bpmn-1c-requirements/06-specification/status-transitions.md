# Разрешённые переходы статусов

При создании после проверки обязательных полей и назначения: высокий приоритет **или** category.requires_approval → `На согласовании`; иначе → `Новая`. Незаполненные обязательные поля блокируют сохранение, статус «Требует уточнения» используется для содержательно неполных уже созданных заявок.

| Из | В | Роль | Предусловие и эффект |
|---|---|---|---|
| Новая | В работе | менеджер | принять назначенную заявку |
| Новая / В работе / На согласовании | Требует уточнения | менеджер / руководитель | записать вопрос; срок не приостанавливается |
| Требует уточнения | Новая / На согласовании | менеджер | информация дополнена; повторить проверку необходимости согласования |
| На согласовании | Согласована | руководитель | сохранить решение и комментарий |
| На согласовании | Отклонена | руководитель | обязательная причина отказа; терминальный статус |
| Согласована | В работе | менеджер | передать исполнителю |
| В работе | Выполнена | исполнитель | записать результат выполнения |
| Выполнена | В работе | менеджер | результат не принят; обязательная причина возврата |
| Выполнена | Закрыта | менеджер | результат принят; система заполняет closed_at |

Иные переходы запрещены, в том числе прямые «Новая → Закрыта», «На согласовании → В работе». Закрыта и Отклонена — терминальные. Администратор управляет справочниками, но не обходит маршрут заявки. История хранит старый/новый статус, время, пользователя, причину; пользователь не удаляет её.
