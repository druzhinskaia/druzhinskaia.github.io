# Показатели

| Показатель | Правило |
|---|---|
| Выручка | сумма исходного revenue |
| Прибыль | сумма revenue − cost |
| Маржинальность | сумма прибыли / сумма выручки; при нуле недоступна |
| Баланс оценок 1–5 | доля оценок 5 − доля оценок 1–3, п.п.; не NPS |
| Доля проблем | feedback_reason != «нет проблемы» |
| Время ответа | среднее response_time_hours; ноль допустим |
| Доля возвратов | среднее is_return |

Количество и результаты анализа не являются доказательством экономии времени или роста продаж.
