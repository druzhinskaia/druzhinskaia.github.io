# Описание данных

| Поле | Описание |
|---|---|
| order_id | номер заказа |
| order_date | дата заказа |
| customer_id | идентификатор клиента |
| region | регион клиента |
| channel | канал поступления заказа |
| manager | ответственный менеджер |
| category | категория товара |
| product | продукт |
| quantity | количество |
| discount | скидка |
| revenue | выручка |
| cost | себестоимость |
| rating | оценка клиента от 1 до 5 |
| feedback_reason | причина обратной связи |
| response_time_hours | время первого ответа в часах |
| is_return | признак возврата |
| month | месяц заказа, расчетное поле |
| profit | прибыль по заказу, расчетное поле |
| margin_pct | маржинальность заказа, расчетное поле |
| has_problem | признак проблемной обратной связи |
| rating_group | группа оценки клиента |
| rating_balance_group | категории для баланса оценок: positive=5, neutral=4, negative=1–3 |

Исходные данные предоставлены автором проекта.

## Баланс оценок 1–5

Баланс = (доля оценок 5 − доля оценок 1–3) × 100, в процентных пунктах. Это описательный показатель текущей шкалы. Для NPS нужен отдельный вопрос о рекомендации со шкалой 0–10; такого поля здесь нет.

## Производные поля и ограничения

`rating_balance_group`: positive=5, neutral=4, negative=1–3. Это категории оценок, а не ответы на вопрос о рекомендации. `month` — месяц order_date, `profit` — revenue−cost, `margin_pct` — profit/revenue с пропуском при нулевой выручке. `rating_group` — низкая 1–3, средняя 4, высокая 5. `has_problem` — причина отличается от «нет проблемы». Исходные данные предоставлены автором.
