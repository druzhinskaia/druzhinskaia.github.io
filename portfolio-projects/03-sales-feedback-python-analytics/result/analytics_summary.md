## Ограничения

Выручка и себестоимость берутся из исходных полей без повторного применения скидки. is_return используется для расчёта доли возвратов; корректировка выручки по возвратам без суммы возврата не выполняется. При нулевой выручке маржинальность недоступна. Динамика повторных покупок и причинное влияние на продажи здесь не исследуются.
