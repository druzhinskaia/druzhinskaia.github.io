# Формульная модель

- `04_checks`: IF, OR/AND, COUNTIF, LEN, ISNUMBER, MOD, ABS, INDEX/MATCH. Проверка неоднозначной ссылки выполняется до зависимого поиска.
- `10_events`: D=is_error, K=нарастающий счётчик, J=номер события только для ERROR. Метаданные правила и источник строки не зависят от сортировки компактного реестра.
- `05_errors`: H вычисляет позицию очередного события через MATCH, A:G используют INDEX по одной найденной позиции. При отсутствии события строка пуста.
- `06_summary`: число событий берётся из общего счётчика 10_events, критичность и типы — COUNTIFS по тем же событиям; доля записей — COUNTIF(error_count, >0) / число записей.
- `09_parameters`: дата среза, денежный допуск, вместимость и индикатор переполнения реестра.

LEN(cell&"")=0 отличает пустоту от допустимого числового нуля. Диапазоны ограничены вместимостью, формулы не используют динамические массивы или функции, появившиеся после Excel 2010. Это совместимость синтаксиса; фактическое поведение Excel 2010 в среде проверки не тестировалось.
