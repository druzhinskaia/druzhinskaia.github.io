# Правила контроля качества

Данные предоставлены автором. Каждое событие имеет ключ entity:source_row:rule_id. Ошибочные данные не удаляются и не исправляются автоматически.

| Правило | Ошибка | Пропуск проверки |
|---|---|---|
| Дубли | ID встречается больше одного раза | пустой ID отдельно относится к обязательным полям |
| Обязательные поля | отсутствует хотя бы одно поле строки | полностью пустая строка не является записью |
| Ссылка | 0 совпадений = Нет связи; >1 = Неоднозначная связь | пустой внешний ID уже отмечен обязательным полем |
| Заказ: расчёт | quantity положительное целое; order_sum = quantity × price в допуске | обязательный операнд отсутствует |
| Клиент: ИНН | длина 10/12, только цифры | ИНН отсутствует; контрольная сумма не проверяется |
| Оплата: сумма | сумма отрицательна или больше суммы однозначно связанного заказа | ссылка неоднозначна/нет связи или сумма отсутствует |
| Цена | отрицательная | цена отсутствует |
| Даты | позже даты среза, некорректный числовой формат; для оплаты раньше заказа | исходная дата отсутствует; сравнение с заказом только при уникальной ссылке |
| Статус | не из разрешённых значений | статус отсутствует |

Заказы: Выполнен, В работе, Отменен, Ожидает оплаты. Оплаты: Оплачено, Частично оплачено, Не оплачено. Нулевая оплата допустима. Дата среза и допуск — `09_parameters!B2:B3`. ERROR — событие, SKIP — невыполненная зависимая проверка, OK — проверка пройдена, N/A — неприменимо.

Критичность: дубли, обязательные поля, ссылки, расчёты, формат ИНН и отрицательные цены — High; даты и статусы — Medium. Доля ошибочных записей = строки с error_count>0 / все заполненные записи. Величина ущерба не оценивается.

Пределы исходников и реестра заданы явно; для другого объёма книгу пересобирают или расширяют все зависимые диапазоны. Нативная проверка Excel/VBA и согласование правил под новый источник обязательны перед регулярным применением.
